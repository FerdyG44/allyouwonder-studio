All You Wonder Studio

A small studio app for one YouTube channel

All You Wonder Studio is a private desktop tool that produces short educational videos for the YouTube channel All You Wonder (@alluwonder) and uploads them to that channel after the channel owner approves each one.

Privacy policy

Effective 26 October 2026 · Applies to All You Wonder Studio

Who runs the app

All You Wonder Studio is operated by Ferdi Gülseren, the owner of the All You Wonder YouTube channel, for that channel only.

What data the app accesses

When the owner signs in with Google, the app asks for one permission: https://www.googleapis.com/auth/youtube.upload. It uses that permission only to:

  • upload videos the owner has approved to the owner's own channel;
  • set each video's title, description, tags, privacy status and release time;
  • set custom thumbnails on those videos.

The app does not read the owner's email, contacts, files, viewing history, analytics or comments, and does not access other users' data.

What is stored and where

  • The Google sign-in refresh token is stored in the macOS Keychain on the owner's computer.
  • For each upload, the app keeps the YouTube video ID, upload status, scheduled time and a file fingerprint (to prevent duplicate uploads) in a local database on the same computer.
  • Nothing is stored on servers run by the app. The app has no servers.

Sharing

YouTube data obtained through the API is not sold, shared with third parties, or used for advertising. The only party that receives data from the app is Google/YouTube, through the official YouTube API Services.

YouTube API Services

All You Wonder Studio uses YouTube API Services. By using it, the owner is bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time on the Google Account permissions page (Security → Third-party apps & services). Revoking access stops the app from uploading immediately.

To delete all data the app has stored:

  • remove the app's sign-in entry (service ai-youtube-studio-youtube) from the macOS Keychain;
  • delete the app's local database file, which holds the upload records;
  • optionally delete uploaded videos in YouTube Studio; the app never deletes videos itself.

Stored API data is kept only as long as it is needed to track uploads, and it is deleted when the owner stops using the app.

Viewers of the channel

The app does not collect any information about people who watch All You Wonder videos. YouTube's own policies apply to viewers.

Changes and contact

Updates to this policy will appear on this page with a new effective date. Questions can be sent through the contact options on the All You Wonder channel's About page on YouTube.
